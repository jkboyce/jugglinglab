
Juggling Lab pattern list files
-------------------------------

These pattern list files are for use with Juggling Lab, the latest version of
which can be downloaded at https://jugglinglab.org.

These are identical to the pattern lists that come packaged with the Juggling
Lab app, with the exception of the "extra" directory that includes some
additional patterns.

If you would like to contribute your own pattern files, please do! Use our
file naming system to keep things organized: Prefix your files with a unique
personal identifier followed by '_', and avoid using any of the characters
`\/?:*"><|` in filenames. Send your files to jboyce@gmail.com, or submit them
as a pull request on Github.

- Jack Boyce (Juggling Lab admin)
